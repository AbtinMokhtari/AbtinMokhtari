# پورتفولیوی آبتین مختاری

یک سایت شخصی فارسی و واکنش‌گرا با HTML، CSS و JavaScript خام.

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای توسعه راحت‌تر می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## شخصی‌سازی
- متن‌ها، مهارت‌ها و نمونه‌کارها در `index.html` هستند.
- رنگ‌ها و ظاهر در ابتدای `style.css` با متغیرهای `:root` تنظیم می‌شوند.
- رفتار منوی موبایل و فعال شدن لینک بخش‌ها در `script.js` است.
- تصویر قهرمان فعلاً یک جایگاه گرافیکی با حروف AM است؛ می‌توانید آن را با عکس خودتان جایگزین کنید.
- لینک تلگرام در `index.html` به `https://t.me/MrAbtinMokhtari` تنظیم شده است. لینک شبکه‌های اجتماعی نمونه را با آدرس‌های واقعی جایگزین کنید.
